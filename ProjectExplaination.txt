Project Explanation

The Game Stats Manager project is designed to organize and analyze basketball player performance data using a structured database approach. The project begins with a dataset of 60 rows of game statistics for five players on the Sharks team. Each row represents a player's performance in a specific match, including points scored, assists, rebounds, opponent, and match result.

 Purpose of the Project

The goal of this project is to demonstrate how real-world sports data can be modeled using database concepts. It shows how to:

- Build a dataset in Excel
- Design an ER diagram to represent relationships between entities
- Create SQL tables to store the data in a relational format
- Understand how players, teams, matches, and stats connect

 What the Project Includes

1. **Excel Dataset (GameStatsData.xlsx)**
Contains all player statistics across multiple games.

2. ER Diagram (ERDiagram.txt)**
Defines the entities: Team, Player, Match, and Stats, and shows how they relate.

3. SQL Tables (tables.sql)**
Includes the SQL code to create the four relational tables.

4. **README.md**
Provides an overview of the project, its structure, and its purpose.

 Summary

This project demonstrates the full workflow of building a data-driven system:
- Creating data
- Structuring it
- Modeling relationships
- Implementing SQL tables

It reflects how databases are used to store and analyze performance data in real sports analytics systems.
